Доставка СДЭК до пункта выдачи. Расчёт стоимости через API, выбор ПВЗ на карте, создание заказов, трекинг, этикетки.

== Description ==

Полная интеграция WooCommerce с СДЭК через официальный API v2.0 для доставки по схеме «Склад → СДЭК → ПВЗ клиента».

= Расчёт стоимости =

* Динамический расчёт через CDEK API v2.0 (calculator/tariff)
* Тарифы: 136 (Посылка), 234 (Экономичная), 368/378 (Постамат)
* Автовыбор дешевейшего тарифа
* Наценка: фиксированная (₽) + процентная (%)
* Бесплатная доставка от заданной суммы
* Отображение сроков (N–M дн.)

= Выбор ПВЗ =

* Яндекс.Карта с кластеризацией маркеров
* Список ПВЗ с адресами, графиком, иконками (💵💳👔)
* Поиск по адресу / названию
* Сброс при смене города
* Валидация: обязательный выбор ПВЗ перед заказом
* ПВЗ код сохраняется в мете заказа

= Создание заказов в СДЭК =

* Кнопка «Отправить в СДЭК» в карточке заказа
* Авто-расчёт грузоместа из товаров (вес, габариты, укладка стопкой)
* Трек-номер СДЭК + ссылка отслеживания
* Кнопка «Пересоздать заявку»

= Трекинг =

* Крон-синхронизация статусов (каждые 2 часа)
* Ручная кнопка «Обновить статус»
* Авто-завершение заказа при статусе DELIVERED
* Колонка «СДЭК» в списке заказов
* История статусов в мета-боксе

= Печать =

* Скачивание этикетки (PDF) из карточки заказа
* Генерация через CDEK Print API

= Администрирование =

* Мета-бокс: ПВЗ, трекинг, статус, кнопки
* Настройки: API-ключи, Яндекс.Карт ключ, sandbox/production
* Тест подключения к API
* HPOS совместимость (WC 8+)

== Installation ==

1. Скопируйте папку в `wp-content/plugins/`
2. Активируйте плагин
3. WooCommerce → СДЭК — введите API-ключи
4. WooCommerce → Доставка → Зона → Добавить метод → «СДЭК — ПВЗ»
5. Настройте город отправки, наценки, тарифы
