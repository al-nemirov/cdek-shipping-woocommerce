# СДЭК Доставка — ПВЗ для WooCommerce

**WordPress-плагин** для интеграции WooCommerce с СДЭК через официальный API v2.0.  
Схема: курьер СДЭК забирает посылки с вашего склада → доставляет в ПВЗ клиента.

---

## Возможности

### 🛒 Расчёт стоимости
- Динамический расчёт через CDEK API v2.0
- Настраиваемый тариф (рекомендуем **481** — Экспресс дверь-склад)
- Наценка фиксированная (₽) + процентная (%)
- Бесплатная доставка от заданной суммы
- Срок доставки в названии метода (N–M дн.)

### 🗺 Выбор ПВЗ на карте
- Яндекс.Карты с кластеризацией маркеров
- Список ПВЗ с адресами, графиком, иконками (💵💳👔)
- Поиск по адресу / названию
- Сброс ПВЗ при смене города
- Валидация: обязательный выбор ПВЗ перед оформлением

### 📦 Создание накладных
- Кнопка «Отправить в СДЭК» в карточке заказа
- Авто-расчёт веса и габаритов из товаров заказа
- Трек-номер + ссылка для отслеживания
- Печать этикетки PDF
- Кнопка «Пересоздать заявку»

### 🚚 Вызов курьера (один забор в день)
**WooCommerce → СДЭК Курьер**:
- Чеклист СДЭК-заказов, ожидающих отправки (сегодняшние — авто-отмечены)
- Старые заказы, ещё не переданные
- Выбор даты и интервала (вкл. ночной 22:00–06:00)
- Авто-подсчёт суммарного веса
- Создание / отмена заявки через API (`POST /intakes`)

### 📋 Страница «Заказы — Отправка»
**WooCommerce → 📦 Заказы отправки** — чистый список без лишнего:
- Фильтры: Все / Сегодня / СДЭК / Яндекс / Ждут СДЭК / Отправлено СДЭК
- Сводка: сегодня / ждут СДЭК / в СДЭК / ждут МС
- Статус СДЭК и МойСклад в одной строке
- Быстрые кнопки: «СДЭК →», «↻ СДЭК», «МС →», «✏️»
- Поиск по номеру или имени

### 📊 Трекинг
- Крон-синхронизация статусов каждые 2 часа
- Ручная кнопка «Обновить статус»
- Авто-завершение заказа при DELIVERED
- Колонка «СДЭК» в стандартном списке заказов

## Установка

1. Скопируйте папку в `wp-content/plugins/`
2. Активируйте плагин
3. **WooCommerce → СДЭК** — введите API-ключи и данные склада
4. **WooCommerce → Доставка → Зона → Добавить метод → «СДЭК — ПВЗ»**

---

## Настройка

### API-ключи
Получить в [ЛК СДЭК](https://lk.cdek.ru) → Настройки → Интеграция → API.

```
Account (Client ID):     ваш_client_id
Secure (Client Secret):  ваш_client_secret
Тестовый режим:          выкл (боевой api.cdek.ru)
```

### Данные склада-отправителя

| Поле | Пример |
|------|--------|
| Компания | ООО Ваша Компания |
| Контактное лицо | Иванова Анна |
| Телефон склада | +79001234567 |
| Код города СДЭК | 44 (Москва), 137 (СПб) |
| Адрес склада | г. Москва, ул. Примерная, д. 1 |
| Описание груза | Книги |

### Тариф

| Сценарий отправки | Тариф | Код |
|-------------------|-------|-----|
| Привозите в ПВЗ СДЭК сами | Экспресс склад-склад | **483** |
| Курьер СДЭК забирает у вас | Экспресс дверь-склад | **481** |

> ⚠️ **Важно**: тарифы «Посылка» (136), «Эконом» (234/368) могут быть заблокированы вашим договором СДЭК. Если API возвращает `ve_tariff_is_not_available_for_payment_type` — потребуйте у менеджера включить эти тарифы: они значительно дешевле.

## Схема работы

```
Клиент выбирает СДЭК → ПВЗ на карте → оплачивает онлайн
       ↓
Менеджер: WooCommerce → Заказы отправки
  → «СДЭК →»: регистрирует накладную, скачивает этикетку
       ↓
Менеджер: WooCommerce → СДЭК Курьер
  → отмечает заказы, дату/время → «Сформировать заявку»
  → курьер СДЭК приезжает на склад, забирает все посылки
       ↓
СДЭК: курьер → сортировочный центр → ПВЗ клиента
  → клиент получает СМС автоматически
```

## Технические детали API

### Тип заказа
Плагин использует `"type": 2` (доставка), а не `type: 1` (интернет-магазин).  
Это критично — `type: 1` требует отдельного типа договора и даст ошибку `err_currency_empty`.

### Пример payload накладной
```json
{
  "type": 2,
  "tariff_code": 481,
  "from_location": { "code": 44, "address": "г. Москва, ул. ...", "postal_code": "107023" },
  "delivery_point": "SPB335",
  "sender": { "company": "Ваша Компания", "name": "Иванова Анна", "phones": [{ "number": "+79001234567" }] },
  "recipient": { "name": "Иван Иванов", "phones": [{ "number": "+79001234568" }], "email": "client@mail.ru" },
  "packages": [{ "number": "PKG-12345", "comment": "Книги", "weight": 500, "length": 25, "width": 20, "height": 5 }]
}
```

### Доступные тарифы (тип договора «Экспресс»)
| Код | Тариф | Назначение |
|-----|-------|-----------|
| 483 | Экспресс склад-склад | ПВЗ → ПВЗ, самопривоз |
| **481** | **Экспресс дверь-склад** | **ПВЗ, курьер забирает у вас** |
| 485 | Экспресс дверь-постамат | Постамат, курьер забирает |
| 62  | Магистральный склад-склад | Межрегион, самопривоз |
| 123 | Магистральный дверь-склад | Межрегион + курьер |
