# СДЭК Доставка — WooCommerce

Плагин интеграции WooCommerce с [СДЭК](https://www.cdek.ru/) через официальный API v2.0 для доставки до пункта выдачи (ПВЗ).

## Схема доставки

```
Склад магазина → СДЭК → ПВЗ клиента
```

Магазин сам отправляет посылки в СДЭК, плагин рассчитывает стоимость, показывает клиенту ПВЗ на карте и создаёт заказы через API.

## Возможности

### Расчёт стоимости
- Динамический расчёт через CDEK API v2.0 (`/calculator/tariff`)
- Тарифы: 136 (Посылка склад→ПВЗ), 234 (Экономичная), 368/378 (Постамат)
- Автовыбор дешевейшего доступного тарифа
- Наценка: фиксированная (₽) + процентная (%) поверх цены СДЭК
- Бесплатная доставка от заданной суммы заказа
- Отображение сроков доставки (N–M дн.)

### Выбор ПВЗ на чекауте
- Интерактивная карта Яндекс с кластеризацией маркеров
- Список ПВЗ с адресами, графиком работы, иконками (💵💳👔)
- Поиск по адресу внутри модалки
- Автоопределение города из формы заказа
- Сброс ПВЗ при смене города
- Валидация: обязательный выбор ПВЗ перед оформлением
- Полноэкранная модалка на мобильных (карта сверху, список снизу)

### Создание заказов в СДЭК
- Кнопка «Отправить в СДЭК» в карточке заказа
- Авто-расчёт грузоместа из товаров (вес, габариты, укладка стопкой)
- Конвертация единиц WooCommerce (кг/г, см/мм)
- Трек-номер СДЭК + ссылка на отслеживание
- Кнопка «Пересоздать заявку» (сброс + повторная отправка)

### Трекинг и статусы
- Крон-синхронизация каждые 2 часа
- Ручная кнопка «Обновить статус»
- Авто-завершение заказа при статусе DELIVERED
- Колонка «СДЭК» в списке заказов WooCommerce
- Цветовая индикация статуса
- История статусов в мета-боксе (из order notes)

### Печать
- Скачивание этикетки (PDF-накладной) из карточки заказа
- Генерация через CDEK Print API

### Администрирование
- Мета-бокс в карточке заказа: ПВЗ, UUID, трекинг, статус, кнопки
- Настройки: API Client ID/Secret, API ключ Яндекс.Карт, sandbox/production
- Тест подключения к API прямо из настроек
- HPOS совместимость (WC 8+)
- Nonce-защита всех AJAX-запросов

## Установка

1. Скопируйте папку в `wp-content/plugins/`
2. Активируйте плагин
3. **WooCommerce → СДЭК** — введите API-ключи (или оставьте пустыми для sandbox)
4. **WooCommerce → Доставка → Зона** → Добавить метод → «СДЭК — ПВЗ»

## Настройки метода доставки

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| Город отправки | Код СДЭК (Москва = 44) | 44 |
| Индекс отправки | Почтовый индекс склада | 107023 |
| Вес по умолч. (г) | Для товаров без веса | 500 |
| Габариты по умолч. (см) | Длина/ширина/высота | 25×20×5 |
| Наценка (₽) | Фикс к стоимости СДЭК | 0 |
| Наценка (%) | Процент к стоимости СДЭК | 0 |
| Бесплатная доставка от (₽) | 0 = выключено | 0 |
| Тарифы | Какие тарифы предлагать | 136, 234 |

## API Endpoints (AJAX)

| Action | Описание |
|--------|----------|
| `cdek_ship_pvz` | Список ПВЗ по городу (nonce) |
| `cdek_ship_cities` | Поиск городов (nonce) |
| `cdek_ship_test_api` | Тест подключения (admin) |
