# Родина — СДЭК Доставка

WooCommerce плагин доставки через СДЭК до пункта выдачи (ПВЗ).

## Схема доставки

```
Магазин (Москва) → Склад СДЭК → ПВЗ клиента
```

Магазин сам отправляет посылки в СДЭК, плагин рассчитывает стоимость и показывает клиенту ПВЗ на карте.

## Возможности

- Расчёт стоимости через CDEK API v2.0
- Тарифы: 136 (Посылка склад→ПВЗ), 234 (Экономичная)
- Выбор ПВЗ на Яндекс.Карте + список с поиском
- Наценка (фикс + %) и бесплатная доставка от суммы
- Автоопределение города по полю checkout
- Код ПВЗ сохраняется в заказе
- Sandbox/Production режим
- Мобильная адаптация модалки ПВЗ

## Установка

1. Скопируйте папку `rodina-cdek-shipping/` в `wp-content/plugins/`
2. Активируйте плагин
3. WooCommerce → СДЭК — введите API ключи (или оставьте пустыми для sandbox)
4. WooCommerce → Настройки → Доставка → Зона → Добавить метод → «СДЭК — ПВЗ»

## Настройки метода доставки

| Параметр | Описание |
|----------|----------|
| Город отправки | Код СДЭК (Москва = 44) |
| Индекс отправки | Почтовый индекс склада |
| Вес/размеры по умолч. | Для товаров без заполненных габаритов |
| Наценка | Фикс ₽ + % к стоимости СДЭК |
| Бесплатная доставка от | Сумма заказа (0 = выключено) |
| Тарифы | Какие тарифы предлагать |

## API Endpoints (AJAX)

| Action | Описание |
|--------|----------|
| `rodina_cdek_pvz` | Список ПВЗ по городу |
| `rodina_cdek_calc` | Расчёт стоимости |
| `rodina_cdek_cities` | Поиск городов |
| `rodina_cdek_test_api` | Тест подключения (admin) |
